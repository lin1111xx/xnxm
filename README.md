# LittlePhone 0.7.0

## 运行
解压并保持目录结构，通过静态服务器打开项目根目录；ES Modules 不建议直接使用 file://。

## 0.7.0 更新
- **桌面图标跨页拖动**：长按拖动图标到屏幕左右边缘自动翻页，跨页放置应用。
- **文件夹系统**：两个图标叠放自动创建文件夹；点击文件夹弹出内容视图；可拖入/拖出应用。
- **Dock 自定义**：拖拽图标进出 Dock，Dock 栏图标完全可配置。
- **应用安装与卸载**：应用中心新增扩展市场，可安装计算器、待办清单、音乐等扩展；扩展应用可卸载。
- **主题与壁纸**：新增多套主题强调色；支持导入本地图片作为自定义壁纸。
- **桌面布局备份与恢复**：设置中可导出/导入桌面布局 JSON（图标排列、文件夹、Dock、壁纸、主题），不含聊天记录和 API Key。
- 保留 0.6.0 全部功能：SSE 流式输出、角色独立聊天、提示词预设、世界书关键词注入、消息编辑删除、上下文长度配置。

## 操作说明
- **长按图标**：进入编辑模式，图标开始抖动
- **拖动图标**：在桌面移动位置，拖到另一个图标上创建文件夹
- **拖到 Dock**：把图标拖到底部 Dock 栏即可加入
- **从 Dock 拖出**：长按 Dock 图标拖回桌面
- **编辑模式下点击 ×**：卸载扩展应用（内置应用不可卸载）
- **点击文件夹**：打开文件夹内容视图

## 已知限制
- 文件夹重命名功能暂未实现，默认为"新建文件夹"。
- 扩展应用目前为占位页面，具体功能将在后续版本完善。
- 图标包系统仅预留接口，暂不支持自定义图标包导入。
- 上下文长度按消息条数限制，不是 token 精确计数。
- 头像和聊天等数据以 localStorage 保存，容量受浏览器限制；不适合长期存放大量图片。
- 备份 JSON 不包含 API Key，导入不会覆盖现有密钥。
- API Key 存在浏览器本地存储；正式商业发行建议使用自有后端代理。
